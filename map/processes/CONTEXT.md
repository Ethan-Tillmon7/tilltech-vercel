# Processes

Movements that actually repeat in this repo, each backed by its commit history. Open the one you're about to do. Each card links to the object cards it touches.

| Card | Status | When |
| --- | --- | --- |
| [add-a-project](add-a-project.md) | verified | New portfolio entry, or new screenshots or video for one |
| [update-the-resume](update-the-resume.md) | verified | A new résumé version (v1.2 → v1.3 → v1.4 so far) |
| [ship-to-production](ship-to-production.md) | verified | Anything here that should reach tilltechnologies.ai |

Every process ends in **ship-to-production**. Nothing done here is live until then.

Add a card only after a movement has happened at least twice. Copy `../_templates/process.md`.
